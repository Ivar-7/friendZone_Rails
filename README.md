# FriendZone

FriendZone is a Ruby on Rails application that helps you connect with friends and build meaningful relationships.

## Features

- User authentication: Sign up, log in, and log out securely.
- Friend requests: Send and accept friend requests to connect with other users.
- Friendship management: View, accept, and remove friends from your friend list.
- Profile customization: Personalize your profile with a profile picture and bio.
- Activity feed: Stay updated on your friends' activities and posts.

## Deployment
